# BuzzBuy - Premium Responsive E-Commerce Store

BuzzBuy is a modern, responsive, and interactive shopping landing page featuring a curated design system, full screen responsiveness, and a persistent dark mode toggle.

## 🚀 Features

- **🌓 Dark Mode Engine**: Seamless transition between dark and light themes with native system preferences detection and persistence in `localStorage`.
- **📱 Fully Responsive Layout**: Custom `@media` queries that adapt grid cells, banners, sliders, and navigation lists dynamically for laptops, tablets, and mobile devices.
- **🍔 Mobile Navigation Menu**: A sleek, sliding drawer menu toggled by an interactive hamburger icon that auto-closes on outside clicks.
- **⚡ Performance Optimized**: Pure HTML, Vanilla CSS, and lightweight Javascript with zero heavy dependencies or framework bloat.
- **🎨 Modern Aesthetics**: Curated color palettes, soft gradients, box-shadows, hover scales, and CSS transitions on interaction points.
- **🎯 SEO Optimized**: Strategic header structure, meta description tags, keywords, semantic tags, and descriptive title configurations.

## 🛠️ Technologies Used

- **HTML5**: Semantic layout markup.
- **CSS3**: Variables, Flexbox, Grid layouts, custom `@media` queries, transitions, and hover animations.
- **JavaScript (ES6)**: State management for theme settings and responsive header menus.
- **Font Awesome 6.5.1**: Scalable icon set for header controls and info boxes.
